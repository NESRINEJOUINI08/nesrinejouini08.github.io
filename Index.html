✨ What This Application Does

magpie-our-free-model is a plugin that connects the Magpie launcher system with the Our Free Model service. In everyday terms, it acts as a friendly middle layer that takes care of the boring parts for you: it finds available free model pools, checks that your access is valid, keeps your accounts organized, and starts or stops the background services you need.

Instead of manually editing configuration files or juggling several tools at once, you install this plugin, point it at your free model pools, and let it manage the rest. A built-in remote console lets you check on things from another device through a temporary Cloudflare link, without creating an account first.

🎁 Key Features

🎯 Free Model Pools

Collects the available free model pools in one place so you can pick the one you want without hunting through separate pages.

🔐 EAC Authorization

Handles EAC authorization for you, so your access is verified the moment the plugin starts rather than on every manual action.

👥 Multiple Account Providers

Register more than one account provider and switch between them whenever you need a different set of model pools.

⚙️ Automatic Service Management

Starts, monitors, and stops the required background services on its own, so nothing is left running when you close the app.

🌐 Accountless Remote Console

Open a temporary Cloudflare link to reach the console from a browser on another device, with no sign-up required.

🪶 Lightweight Setup

Everything runs from a single downloaded item. No long installer chain and no separate dependency you must track down.

🚀 First-Time Setup Walkthrough

  1. Open your web browser and go to the project page.
  2. Download the application file from that page and wait for the download to finish.
  3. Open the folder where the file was saved. On Windows this is usually your Downloads folder.
  4. Start the application by double-clicking the file you downloaded.
  5. If Windows shows a blue or yellow security window asking whether to allow the app to run, choose the option that allows it to continue.
  6. Wait a short moment while the application prepares its workspace and starts its background service.
  7. When the main window appears, open the settings area and add your first account provider.
  8. Confirm that a free model pool appears in the list. If it does, the plugin is connected and ready to use.

You do not need to type commands or open a terminal at any point. Everything is handled through the normal Windows window you see on screen.

🔑 How EAC Authorization Works

EAC authorization is the check that proves you are allowed to use the free model pools you selected. The plugin performs this check quietly in the background the first time it connects.

  • Authorization is tied to the account provider you added during setup.
  • If a check fails, the plugin tells you which provider needs attention instead of failing silently.
  • Adding a second provider gives you a fallback, so one unavailable source does not stop your whole setup.

👥 Working With Multiple Account Providers

You can register more than one account provider in the plugin. Open the account section, choose the option to add a provider, and fill in the fields the window asks for. Give each provider a name you will recognize later, for example "Main" and "Backup".

Once two or more providers are listed, you can select which one is active. The free model pools shown in the interface change to match the active provider, which makes it easy to compare what each one offers.

🧰 Automatic Service Management

The plugin keeps track of the background service it depends on. When you open the application, the service starts. When you close the application, the service stops. If the service becomes unresponsive, the plugin attempts to restart it before showing you an error.

You can review the current state of the service in the status area of the main window. A green indicator means the service is running normally. A grey indicator means it is stopped, which usually happens when the application was closed.

🌐 Using the Temporary Remote Console

The remote console lets you reach the plugin's control panel from another device, such as a phone or a tablet on the same network or anywhere else. It works through a temporary Cloudflare link, and you do not need to create an account to use it.

  1. Open the remote console section inside the application.
  2. Turn the console on. The plugin prepares a temporary address for you.
  3. Copy the address that appears and open it in a browser on your other device.
  4. Use the console to check status or make small adjustments while away from your computer.
  5. Turn the console off when you are done. The temporary address stops working after it is switched off.

🩺 If Something Does Not Look Right

  • The window does not appear: wait a few seconds and check whether the application icon is already running in the taskbar. Click it to bring the window forward.
  • No free model pools are listed: confirm that an account provider is added and marked as active, then refresh the list.
  • Authorization keeps failing: remove the provider entry and add it again with the same details, then restart the application.
  • The remote console link will not open: switch the console off and back on to generate a fresh temporary address.
  • Windows blocks the download: open the file's properties from the right-click menu and choose the option that unblocks it, then start the application again.
